# tv-home

An Apple TV-style home screen for a Hisense VIDAA TV, with Dubai prayer times.
Built on [Clean Your TV for VIDAA](https://github.com/gilbertmsipha/cleanyourtv-vidaa) (MIT, see LICENSE-cleanyourtv-vidaa), itself a port of [CleanYourTV](https://github.com/Gathin23/cleanyourtv).
Prayer times: [Aladhan](https://aladhan.com) method 16 (Dubai).
